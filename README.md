# 🎵 SoundWays Audio Toolkit

An open-source collection of simple audio utilities for musicians, producers, content creators, and developers.

The goal of SoundWays Audio Toolkit is to make useful audio-analysis tools accessible through simple, understandable code.

## 🔊 Current Features

The first utility is a WAV audio analyzer that can display:

- Audio duration
- Sample rate
- Number of channels
- Bit depth
- Peak level
- RMS level

More audio-production and analysis utilities are planned.

## 🚀 Usage

Requires Python 3.

Clone the repository:

git clone https://github.com/amalacletus369-cell/soundways-audio-toolkit.git

Open the project directory:

cd soundways-audio-toolkit

Analyze a WAV file:

python audio_analyzer.py your_audio.wav
